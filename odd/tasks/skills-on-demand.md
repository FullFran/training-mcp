# Skills on demand

Objective: the MCP server serves training-theory skills on demand: a small catalog through `list_skills` and one skill whole through `load_skill`, with three draft skills (hypertrophy programming, fatigue and autoregulation, exercise selection) that lay out positions and their costs instead of picking a methodology.
Branch: `feat/skills-on-demand` from `main` (293e4abc). Delivery: one PR. Test runner: `go test ./internal/... ./cmd/...`. Refs #114, #115.

Assumptions: "deferred" means progressive disclosure through two fixed read tools, not dynamic tool registration, which hosts do not reliably support; skills are global, embedded and read-only (no table, no migration); the Agent Skills format is the one HCS-0001 adopts for its `skill` contribution kind; `allowed-tools` is a request, never a grant (HCS-0005-R002), so skills use `required_tools` to name read tools only; every skill ships as `draft-unreviewed` until a trainer reviews it; the evidence tools of #116 are not a dependency.
